## Phase Goal

> **Goal (verbatim from ROADMAP.md):** A real agent runtime performs a role end to end,
> including pause and resume, while the orchestrator remains unable to tell which runtime
> it is talking to.
>
> **MVP note:** see 07-01-PLAN.md — the ROADMAP Goal line is not in user-story form and no
> story is invented here.

<objective>
Narrow what the spawned agent can natively do to exactly what the role's `tools:` grants
allow, and correct the one place the codebase currently documents a restriction mechanism
that does not exist.

Purpose: `tools/native.py`'s `NATIVE_TOOL_CONTRACT` was written in Phase 6 as a design
contract "Phase 7 implements from", and `tests/unit/test_native_tool_contract.py` currently
proves it is inert. This plan makes `ClaudeCodeWorker` its first real consumer, which
necessarily relaxes that inertness guard — deliberately, with the guard narrowed to an
explicit allowlist rather than deleted. 07-RESEARCH.md also found that four of the table's
`claude_code` entries attribute directory scoping to an approval-policy flag that provides
no such thing; worktree confinement actually comes from the subprocess working directory.
Leaving that prose in place would mislead the next adapter author into searching for a flag
that does not exist.

Output: `allowed_tools_for()` and an `--allowedTools` argv element, corrected contract
prose, and a narrowed-not-deleted reference guard.
</objective>
