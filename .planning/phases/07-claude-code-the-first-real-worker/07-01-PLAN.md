## Phase Goal

> **Goal (verbatim from ROADMAP.md):** A real agent runtime performs a role end to end,
> including pause and resume, while the orchestrator remains unable to tell which runtime
> it is talking to.
>
> **MVP note:** MVP mode is enabled for this phase, but the ROADMAP `**Goal:**` line is not
> in `As a / I want to / so that` user-story form. Per the MVP planning rules a user story is
> **not invented here**. Run `/gsd mvp-phase 07` if a formal user story is wanted.
> Vertical-slice decomposition is applied regardless: Task 1 is a tracer that runs one role
> end to end through the real adapter, and Tasks 2-3 refine that same slice.

<objective>
Make `ClaudeCodeWorker` a real, working `CodingWorker` adapter for the happy path and for
every failure path, wired into `default_registry` under the name `claude-code`.

Purpose: this is the tracer slice for Phase 7. After Task 1 a role configured with
`worker: claude-code` genuinely runs an external agent process and comes back with a
normalized `WorkerResult`, instead of raising `NotImplementedError`. Tasks 2 and 3 harden
that same single path: it must never raise, it must kill a hung child by process group, and
it must never persist an un-redacted transcript into the tree that becomes the PR branch.

Output: `src/dark_factory/workers/claude_code.py`, two new `Settings` fields, a real
registry registration, a reusable fake-`claude`-on-PATH test helper, and a unit suite that
proves all of the above with no live `claude` binary and no live Anthropic credential.

Locked decisions implemented by this plan:
- D-02: credential handling — `Settings.anthropic_api_key: SecretStr | None = None`, no new
  required startup configuration, a typed error naming `ANTHROPIC_API_KEY` at first real use,
  and the value reaching the subprocess only through `build_worker_env(role, env_var_name=..., value=...)`. (Task 1, Task 2)
- D-03: timeout policy — one `Settings.worker_timeout_seconds` knob (env-overridable int,
  default 1800), no per-role override, no hardcoded constant. (Task 1, Task 2)
- D-04: log streaming target — raw stdout/stderr streamed to
  `<run_root>/logs/<role>/attempt-<N>.stdout.log` / `.stderr.log`, reusing `run_root()`, one
  file per attempt per stream, no new persistence concept. (Task 1, Task 3)
</objective>

`_run_streamed(argv, *, cwd, env, stdout_path, stderr_path, timeout) -> tuple[int | None, bool]` opens both log paths in binary write mode and passes those open file objects as `stdout=` and `stderr=` to `subprocess.Popen(argv, cwd=str(cwd), env=env, stdin=subprocess.DEVNULL, start_new_session=True)`, then `proc.wait(timeout=timeout)`.
