## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Alembic → PostgreSQL (DDL) | Schema change applied through the **direct**, non-pooled endpoint; a DDL statement executed through a transaction pooler is the failure mode this boundary exists to prevent. |
| ORM metadata → autogenerate | `Base.metadata` is what `alembic check` compares the live schema against; a table missing from `_OWNED_TABLES` silently changes what the comparison means. |
| Test database → this repository's schema | The test PostgreSQL is a shared throwaway instance that may hold unrelated tables; autogenerate must never propose to drop them. |
