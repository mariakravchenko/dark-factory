<objective>
Expansion slice one: prove the two adversarial properties of the lease the tracer built. Two processes racing the same run produce exactly one execution and one clean exit (SC3), and a process killed while owning a run is not stolen from until the database clock passes its expiry, after which the next process reclaims it and finishes the job (SC4).

Both proofs use two genuinely separate operating-system processes sharing only PostgreSQL. That is not ceremony: single-owner execution is precisely a claim about what two processes can observe of each other, and an in-process simulation shares module state, a warm engine and an identity map, so it can pass while the real thing fails.

Purpose: satisfy HITL-07 and success criteria SC3 and SC4.
Output: three proof files — one statement-level, two process-level.
</objective>

| Process A ↔ Process B, sharing only PostgreSQL | The property under test. Neither process observes the other except through committed rows. |
