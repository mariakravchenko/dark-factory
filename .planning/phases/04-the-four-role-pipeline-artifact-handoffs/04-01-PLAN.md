<objective>
**As a** Dark Factory operator, **I want to** have one engineering role hand its output to the next role as a durable file on disk plus a reference row in Neon, **so that** the pipeline is a sequence of independent role executions rather than one shared agent conversation.

This plan is the phase tracer: it wires **one** artifact (`acceptance_criteria.json`) along the **whole** path — role YAML `inputs` → `FakeWorker` writes the file → schema validation → `ArtifactReference` row committed in the same transaction as the role's `COMPLETED` status → `ContextBuilder` selects it → the next role's `RoleContext` carries its content. Every layer this phase touches is real and production-quality after Task 1; plan 04-02 expands the proven slice to all four roles and all six artifact types.

Purpose: prove the handoff architecture end-to-end on one path before building out four roles' worth of it.
Output: the `artifacts` table + migration, `dark_factory.domain.artifacts`, `dark_factory.artifacts`, `dark_factory.context`, the `inputs` config field, the ARCHITECTURE role, and the runner wiring that joins them.
</objective>
