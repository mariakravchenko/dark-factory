<objective>
**As a** Dark Factory operator, **I want to** be able to grep every artifact, prompt, event payload, log and report a run produced — including a run that failed on a capability denial — and find none of my secrets, **so that** the audit trail this project's core value depends on is one I can actually share, attach to a ticket, or hand to a reviewer.

This plan closes the phase. Task 1 proves ROADMAP SC4 against the one new failure path this phase introduced: a capability denial, which is the phase's new writer of both an `error` column and an event payload, and therefore the phase's new opportunity to leak. Task 2 builds the Phase 6 acceptance gate — the sibling of the Phase 2/3/4/5 gates — mapping every success criterion and every requirement id to a proof file that must exist and must contain tests.

Purpose: SEC-01 is a whole-project constraint, and every phase that adds a new persisted string is a new chance to break it. The gate exists because the failure mode this project actually has is not a wrong assertion, it is a proof file that quietly disappeared in a later refactor.
Output: the SEC-01 sweep, the Phase 6 acceptance gate, and a completed `06-VALIDATION.md`.
</objective>
