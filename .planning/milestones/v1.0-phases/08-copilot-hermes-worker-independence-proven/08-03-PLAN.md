<objective>
Close QUAL-03 literally: each real worker adapter gets its own integration test suite that
is **skipped, not failed**, when that runtime's binary or credential is absent — and prove
ROADMAP SC4, that each adapter's declared `WorkerCapabilities` match its observed
behaviour.

Purpose: 08-RESEARCH.md's Scope Correction is load-bearing here. `grep -rn "skipif" tests/`
returns nothing in the current tree, and ROADMAP maps QUAL-03 to Phase 8 only — so Phase 7
never built this for `claude-code` either. Phase 7 proved `ClaudeCodeWorker` entirely
against a faked executable on `PATH`, which is a different thing from a suite that runs for
real when the binary and credential are present and skips cleanly otherwise. This plan
therefore ships **three** live suites, not two, closing a gap Phase 7 left open under an
adjacent-sounding name.

Purpose, second half: these modules are also the deferred live spike D-02 promised. They
are written now and execute automatically the day either CLI is installed, with zero code
change required to make them run.

Output: three live integration modules, one shared skip-condition helper, a guard that a
newly registered real adapter cannot ship without a live suite, and an SC4 proof module.

Locked decisions implemented by this plan:
- D-02: the live spike is deferred, not skipped — `pytest.mark.skipif` guarding on
  CLI/credential absence is QUAL-03's own literal requirement, so these suites are the
  mechanism that makes the deferral honest rather than a gap. (Tasks 1-2)
</objective>
