<objective>
The phase's fourth success criterion, proven the only way it can honestly be
proven: drive one real run seeded with realistically-shaped fake credentials all
the way to a published pull request, then sweep every sink Dark Factory controls
for the raw secret strings.

Purpose: D-08 is explicit that this is a full integration test and not a
redaction-unit test, and this phase has already demonstrated why. The
clarification-comment body bypassed `redact()` entirely for two phases while
`redact()` itself was correct and well-tested, and the persisted sibling column
*was* scrubbed — so every narrower proof would have passed. A whole-pipeline
sweep is the only shape of test that finds a call site which forgot to call.

D-08 sinks plus this phase's own four new CLI surfaces.
